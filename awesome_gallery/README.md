# Awesome Gallery

A simple and modern image gallery application built with Flutter.

Awesome Gallery allows users to browse images in a grid and tap on an image to view it in detail.

## Features

* 📸 Display images in a 3-column grid
* 🖼️ View images in full screen
* 👆 Tap on an image to open it
* ↩️ Return to the gallery with the back button
* 🎨 Dark and minimal UI
* 📱 Responsive gallery layout

## Flutter Concepts

This project was created to practice and demonstrate Flutter `Container` concepts:

* `width` and `height`
* `alignment`
* `color`
* `padding` and `margin`
* `border`
* `borderRadius`
* Nested widgets
* `GestureDetector`
* `GridView`

* `StatefulWidget` and `setState`

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd awesome_gallery
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
