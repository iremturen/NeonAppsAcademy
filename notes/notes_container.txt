| Yöntem                                | Örnek                      | Ne olur?                                                            |
| ------------------------------------- | -------------------------- | ------------------------------------------------------------------- |
| **1. Sabit genişlik + yükseklik**     | `width: 200, height: 200`  | Tam olarak 200×200 olur                                             |
| **2. Sadece width**                   | `width: 200`               | Genişlik 200 olur, yükseklik bulunduğu yere/içeriğe göre belirlenir |
| **3. Sadece height**                  | `height: 200`              | Yükseklik 200 olur, genişlik bulunduğu yere/içeriğe göre belirlenir |
| **4. Hiçbirini vermemek**             | `Container()`              | İçeriğine ve parent'ın verdiği alana göre boyutlanır                |
| **5. Ekranın tamamını kaplamak**      | `double.infinity`          | Verilen alanda mümkün olan maksimum boyutu alır                     |
| **6. Ekran boyutuna göre hesaplamak** | `MediaQuery`               | Telefon/tablet ekranının boyutuna göre hesaplanır                   |
| **7. Parent'a göre boyutlanmak**      | `Expanded`, `SizedBox` vb. | Bulunduğu widget'ın verdiği alana göre boyutlanır                   |
| **8. Oransal boyut**                  | `ekran genişliği * 0.5`    | Örneğin ekranın %50'si kadar olur                                   |

2. Alignment
alignment, Container'ın içindeki child widget'ın nerede duracağını belirler.

Container(
  width: 200,
  height: 200,
  alignment: Alignment.center,
  child: Text("Hello"),
)

Burada:
Container → 200 x 200
alignment: Alignment.center → child'ı ortaya yerleştirir.
child: Text("Hello") → Container'ın içindeki yazıdır.
Önemli
alignment, Container'ın kendisinin ekrandaki yerini değil, içindeki child'ın Container içerisindeki yerini belirler.

Alignment.topLeft       → sol üst
Alignment.topCenter     → üst orta
Alignment.topRight      → sağ üst

Alignment.centerLeft    → orta sol
Alignment.center        → tam orta
Alignment.centerRight   → orta sağ

Alignment.bottomLeft    → sol alt
Alignment.bottomCenter  → alt orta
Alignment.bottomRight   → sağ alt

color → arka plan rengi -> 0x → hexadecimal olduğunu belirtir-FF → opacity (şeffaflık)-5733 → renk -> romRGBO(255, 0, 0, 1),
padding → içeride boşluk
margin → dışarıda boşluk
decoration → border, border radius vb.

padding nedir?
Padding = Container'ın kenarı ile içindeki child arasındaki boşluk.
EdgeInsets ne?
EdgeInsets, bu boşluğun nerelerde ve ne kadar olacağını söylemek için


padding: EdgeInsets.all(20),
→ Dört taraftan 20 boşluk.

EdgeInsets.symmetric(
  horizontal: 20,
  vertical: 10,
)

→ Sağ-sol 20, üst-alt 10.

EdgeInsets.only(
  left: 20,
)
→ Sadece sol taraf 20.

EdgeInsets.fromLTRB(10, 20, 30, 40)
→ Sırasıyla **left, top, right, bottom**.

Margin
margin, Container'ın dışındaki boşluğu belirler.
margin: EdgeInsets.all(20) -> Bu, Container'ın dört tarafında 20 birim dış boşluk bırakır.
!Margin için de aynı padding gibi keyword kullanımları var

decoration
Container'ın görsel tasarımını belirlemek için kullanılır.
border
köşe yuvarlama
gölge
gradient
gibi şeyleri burada tanımlarız.
decoration içerisine genellikle BoxDecoration veririz.

decoration
    ↓
BoxDecoration
    ↓
border
    ↓
Border.all
    ↓
color → kenarlığın rengi
width → kenarlığın kalınlığı
decoration: BoxDecoration(
  border: Border.all(
    color: Colors.black,
    width: 2,
  ),
),

BorderRadius.circular(20) → tüm köşeleri aynı yuvarlar
BorderRadius.only(...)    → istediğin köşeleri ayrı ayrı ayarlarsın
BorderRadius.all(...)     → tüm köşelere aynı Radius verir
borderRadius: BorderRadius.only(
  topLeft: Radius.circular(20),
  topRight: Radius.circular(20),
),
