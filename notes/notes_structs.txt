Class → NeonAcademyMember ve ContactInformation oluşturmak.
Property / field → String, int gibi tiplerle class'ın özelliklerini tanımlamak.
Constructor → Nesne oluştururken bilgileri vermek.
Named parameters → fullName:, age: gibi isim vererek parametre geçirmek.
required → Constructor'daki bilgilerin verilmesini zorunlu yapmak.
Object / instance → ContactInformation(...) ve NeonAcademyMember(...) ile gerçek nesneler oluşturmak.
Composition / object ilişkisi → NeonAcademyMember içinde ContactInformation nesnesi bulundurmak.
List<T> → Birden fazla NeonAcademyMember nesnesini listede tutmak.
add() → Oluşturduğun nesneleri listeye eklemek.
Property'ye erişmek → member.fullName, member.contactInformation.email gibi.
import → Class'ları farklı Dart dosyalarından kullanmak.
print() → Oluşturduğun nesnelerin/verilerin çıktısını görmek.
